Hey there! 👋 I'm **Arpan Pramanik**, an **AI/ML Engineer & Full-Stack Architect** passionate about bridging cutting-edge artificial intelligence with resilient, production-grade cloud systems. I specialize in designing **autonomous agentic workflows, low-latency RAG architectures, physics-grounded agronomy engines, and observable multi-portal enterprise SaaS**.

### 🌟 What I Bring to the Table

* 🧠 **Production Generative AI & Agents:** Architecting resilient RAG systems, multi-LLM failover routing, dense vector stores (`pgvector`, `ChromaDB`, `FAISS`), and anti-hallucination guardrails.
* 🔬 **Scientific Rigor & Explainable AI (XAI):** Designing custom multi-headed CNNs and transfer learning models with **Grad-CAM interpretability** for real-world automated inspection.
* ⚡ **High-Performance Full-Stack SaaS:** Building reactive microservices with **Next.js, React, FastAPI, Node.js & Express** with real-time SSE telemetry and role-based access control.
* 📊 **Enterprise Observability & Cloud:** Instrumenting production distributed tracing, structured logging, and metrics using **OpenTelemetry, Prometheus, Pino, Docker & AWS**.
